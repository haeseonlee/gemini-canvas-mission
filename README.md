# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 1.유틸리티 앱 💻

### 앱 이름: 스마트 메모장
### 카테고리: 유틸리티 앱

### 배포 링크
https://gemini.google.com/share/8d79f79ae357

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?

    일정이나 해야 할 일들, 공부했던 기록을 보기 쉽게 정리하고 요약해주는 기능이 필요했습니다. 
    처음부터 가독성 있고 깔끔하게 정리하는 일이 불편했기 때문에 ai의 도움을 받아 해결하려했습니다.
- 이 앱을 언제, 어떻게 사용할 건가요?
    
    앞으로 주어진 일정에 대한 내용, 페어프로그래밍이나 팀 프로젝트에서 기록해야할 내용들을 메모장에 그때그때 기록하여 저장한 다음 
    ai 요약 정리를 활용할 계획입니다. 

### 주요 기능
- 기능 1

    필요한 메모 제목과 내용을 저장합니다.
- 기능 2
    
    저장된 메모를 수정하고 삭제합니다.
- 기능 3

    가독성 없이 아무렇게나 적어놓은 기록을 ai가 내용 다듬기, 핵심 포인트, 할일 추천을 통해 정리합니다.
- 기능 4

    메모가 여러 개 존재하는 경우 ai 전체 요약을 누르면 모든 메모를 3-4줄 정도로 간단하게 요약해줍니다.

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?

    적어놓은 메모를 요약해주는 기능입니다. 

- AI 기능이 앱에서 어떤 역할을 하나요?

    메모장에 복잡하게 적어놓은 기록을 ai가 내용을 다듬어 가독성 있게 만들고, 핵심 포인트를 3-4가지 정도로 요약합니다. 
    사용자가 메모장에 적어놓은 내용을 토대로 현재 사용자가 해야할 일을 추천해주는 역할을 합니다. 

## 2. 게임 앱  🎮
### 앱 이름: 길건너기 게임
### 카테고리: 게임 앱

### 배포 링크
https://gemini.google.com/share/dd04ca677e3b

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
    
    어렵고 복잡한 게임보다 쉽고 간단하게 즐길 수 있는 게임이 필요했습니다. 
- 이 앱을 언제, 어떻게 사용할 건가요?

    공부하다가 집중력이 떨어지거나 휴식을 취할 때 간단하게 즐길 계획입니다.

### 주요 기능
- 기능 1

    자동차들이 15차선 도로를 달립니다.
- 기능 2

    캐릭터가 위,아래,좌,우로 움직입니다.
- 기능 3

    캐릭터가 자동차에 부딪히면 게임이 종료됩니다.
- 기능 4

    캐릭터가 무사히 길을 건너면 다음 단계로 넘어가게 되고 난이도는 점점 상승합니다.
